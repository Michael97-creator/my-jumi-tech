# JUMI TECH — Flagship Company Website + Academy

Premium Jumi Tech company website with a Jumi Tech Academy registration and onboarding flow.

## Academy flow
1. Student registers on the website.
2. Registration is submitted through Formspree.
3. Student is directed to the Jumi Tech Academy Waitlist.
4. The Waitlist is the onboarding community for free classes, resources, announcements, payment information and preparation.
5. Tuition: ₦30,000. Upcoming cohort: October 5, 2026.

## Formspree
The Academy registration form uses the configured Formspree endpoint. No Paystack, Supabase, payment portal or payment backend is required.

## Deployment
This package can be deployed as a static site on Vercel, Netlify or similar hosting.
